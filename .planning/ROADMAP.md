# Roadmap

## Milestone 1: Stabilization & Operational Core
Focus on hardening existing features and ensuring financial integrity before the full rollout.

- [ ] **Phase 1: Project Initialization & Health**
  - Initialize project state and verify codebase health.
  - Setup GSD workflow automation.
- [ ] **Phase 2: POS Session & Financial Integrity**
  - Implement robust Start/End session workflows in POS.
  - Fix any RLS policy issues in accounting tables.
  - Ensure automated journal postings for all transactions.
- [ ] **Phase 3: Intelligent Procurement**
  - Finalize AI extraction for Purchase Orders.
  - Fix supplier data display and automated linking.

## Milestone 2: User Experience & Deep Automation
Focus on the "beginner friendly" goal and increasing automation efficiency.

- [ ] **Phase 4: Onboarding & Educational UX**
  - Implement guided tours for new merchants.
  - Create context-aware "Accounting Guides" and setup wizards.
- [ ] **Phase 5: Advanced Automation Agents**
  - Enhance AI expense classification accuracy.
  - Implement automated stock alerts and low-inventory reordering.

## Milestone 3: Compliance & Market Rollout
Ensuring local compliance and launching the public presence.

- [ ] **Phase 6: Malaysian E-Invoicing (MyInvois)**
  - Full rollout of LHDN MyInvois integration.
  - Automated SST-02 reporting and filing preparation.
- [ ] **Phase 7: Public Presence & Scale**
  - Launch Pricing, Solutions, and Platform landing pages.
  - Optimize production build and Vercel scaling.
